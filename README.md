# Harmony eDelivery Access - Dynamic Discovery Client

![Harmony eDelivery Access logo](img/harmony-logo.png)

## About the Repository

This repository contains the source code of the Dynamic Discovery Client dependency of Harmony eDelivery Access.

Harmony eDelivery Access by [NIIS](https://niis.org) is a free and actively maintained open-source component for joining one or more eDelivery policy domains.

Harmony Dynamic Discovery Client is based on upon the [Dynamic Discovery Client](https://ec.europa.eu/digital-building-blocks/code/projects/EDELIVERY/repos/dynamic-discovery-client/) open source project by the [European Commission](https://ec.europa.eu/).

## Documentation

The official Harmony documentation is available in a separate repository that can be found [here](https://github.com/nordic-institute/harmony-common/).

## Build

Harmony Dynamic Discovery Client can be built using the following command:

    ./mvnw clean install
